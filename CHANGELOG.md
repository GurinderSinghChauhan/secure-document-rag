# Changelog

This project follows [Semantic Versioning](https://semver.org/). Released changes are recorded here; GitHub also generates release notes from merged commits.

## 0.3.0 - 2026-08-21

- Added super-admin chat response quality evaluations.
- Added organization-admin indexed document inventory and deletion controls.
- Added a version endpoint and automated validation and release workflows.

Versions before `0.3.0` were development snapshots and were not managed through the release workflow.
